# Portfolio (React + Vite)

1. Copy your `images/assets/` folder into `public/images/assets/` (needs `logo_circle.jpg`, `profile.jpg`).
2. `npm install`, then `npm run dev`
3. Edit text, skills and projects in `src/data/content.js`
4. Deploy: `npm run deploy` (publishes `dist` to the `gh-pages` branch)
